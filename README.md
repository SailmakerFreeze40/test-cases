Валидация email - адреса

1.	Название: 		ввод валидного email-адреса
	Шаги воспроизведения:   1) Ввести в поле ввода email «k@academy.ru»
				2) Нажать кнопку «Проверить»	
	Ожидаемый результат: 	появился alert с текстом «Прекрасный email-адрес»

2.	Название:		ввод невалидного email-адреса
	Шаги воспроизведения:	1) Ввести в поле ввода невалидный email «artHot@ma@ru.com»
				2) Нажать кнопку «Проверить»
	Ожидаемый результат:	выводится ошибка красного цвета над кнопкой «Проверить» с текстом «Введен некорректный email»

3.	Название:		ввод email-адреса без @
	Шаги воспроизведения:	1) Ввести в поле ввода заведомо валидный email, но без «@»: «kacademy.ru»
				2) Нажать кнопку «Проверить»
	Ожидаемый результат:	выводится ошибка красного цвета над кнопкой «Проверить» с текстом «Введен некорректный email»

4.	Название:		ввод email-адреса с пробелом внутри
	Шаги воспроизведения:	1) Ввести в поле ввода заведомо валидный email, но с пробелом: «k @academy.ru»
				2) Нажать кнопку «Проверить»
	Ожидаемый результат:    выводится ошибка красного цвета над кнопкой «Проверить» с текстом «Введен некорректный email»
